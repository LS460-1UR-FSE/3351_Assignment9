# REST API Testing Evidence

## Testing Method

This assignment expands on assignment 8 by replacing local memory stored tasks with a PostGreSQL db. 
Tasks are saved when the express server restarts. 

Each task contains:
 id: an integer generated by PostgreSQL
 title: the task name
 completed: a boolean indicating whether the task is finished

The database also contains a category column with a default of
"General"; the current API does not use it.

github: 
https://github.com/LS460-1UR-FSE/3351_Assignment8

## Endpoints

| Test | Endpoint | Expected status | Observed status |
| -----| ---------| --------------- | --------------- |

| GET | /api/items | Retrieve all tasks | 200 |
| GET | /api/items/:id | Retrieve one task | 200 |
| POST | /api/items | Create a task | 201 |
| PUT | /api/items/:id | Update title, completed, or both | 200 |
| DELETE | /api/items/:id | Permanently delete a task | 200 |

POST requires a string title and cannot be empty. It creates a task with a default completion set to "false"

Missing tasks return 404, invalid titles or completion values return 400, db errors cauufht by the routes return 500
